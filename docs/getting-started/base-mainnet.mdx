---
title: "Base Mainnet"
description: "The production network used by Zonk.fun."
---

| Setting | Value |
| --- | --- |
| Network | Base Mainnet |
| Chain ID | `8453` |
| Native gas and curve reserve asset | ETH |
| Explorer | [BaseScan](https://basescan.org) |
| Product | [zonk.fun](https://zonk.fun) |

The frontend rejects non-Mainnet chain configuration and exposes Base as its only active wagmi chain. If your wallet is on another network, use the wallet network selector or the application prompt to switch to Base.

<Note>
  ETH must be on Base Mainnet. Assets on Ethereum Mainnet or another L2 are not automatically available on Base.
</Note>
